# Portfolio Review Checklist

Use this checklist before sharing the portfolio with recruiters or reviewers.

## Project quality
- README explains the problem, solution, architecture, and setup.
- A reviewer can run the project using documented steps.
- Security-sensitive projects include threat considerations and test coverage.
- Screenshots or demos show the real project interface.

## Engineering evidence
- Commits describe the actual change.
- Tests cover important success and failure paths.
- CI status is visible where applicable.
- Configuration examples do not contain real secrets.

## Presentation
- Project names and descriptions are consistent across repositories.
- Links point to working repositories or demos.
- The profile README highlights current cybersecurity projects and measurable engineering work.

## Final check
Run the documented setup and test commands on a clean environment before presenting the project.
